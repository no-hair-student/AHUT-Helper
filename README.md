# AHUT-Helper 
融合晚寝自动打卡保障、青果教务手账课表、可视化方格编辑、课前智能提醒、成绩极速查询与考研目标倒计时。

- 在线体验站点: http://ahutdaliysign.dpdns.org
- 项目作者: [no-hair-student](https://github.com/no-hair-student)

---

## 核心功能介绍

### 1. 晚寝自动打卡与免查寝保障
- 智能自动化签到: 遵循每日晚寝作息，全自动化定时执行打卡任务。
- 异常容灾与重试机制: 遇到网络波动或接口超时自动多轮重试，保障打卡成功率。
- 多渠道状态推送: 签到结果支持 Web Push 原生横幅推送、微信通知及邮件凭证备份。

### 2. 青果教务手账课表与 0 毫秒秒开
- 一键增量同步: 直接对接青果教务系统拉取最新学期课表，增量合并官方排课。
- 本地持久化与 0 毫秒呈现: 课表数据经本地数据库优化缓存，打开即呈现，无需等待外网慢速连接。
- 方格可视化手账编辑: 点击课表任意方格即可添加/编辑考试考场、自习日程及社团活动，支持专属分类徽章管理。

### 3. 课前与考前 15 分钟智能 Web Push 原生横幅
- 智能作息映射: 针对上午 (08:00, 10:05)、下午 (14:00, 15:55)、晚间 (19:00, 21:30) 作息时间表，自动提前 15 分钟下发系统级通知。
- 自定义日程提前量: 支持为自行添加的期末考试和自习日程设置精确时间，提前 15 分钟下发专属横幅。
- 严格遵循静默原则: “有课有安排才推送，没课没安排静默不打扰”，绝不打扰周末与无课休息。

### 4. 成绩极速查询与考研看板
- 青果教务直连查分: 自动激活会话凭据，首次查询 100% 极速命中，提供学期全量成绩列表。
- 考研倒计时小组件: 自定义考试目标与倒计时看板，配合马鞍山实况天气预报，督促日常学业与备考。

### 5. 经典黑板手账质感与跨端体验
- 经典黑板手账风格: 炭黑手绘手账质感，支持深浅模式一键切换 (🌓)。
- PWA 原生应用体验: 支持一键安装至手机桌面与 PC 端桌面，独立窗口秒开运行。

---

## 技术架构

- 服务架构: Python / Flask / Gunicorn 进程池
- 数据引擎: 本地高性能存储与会话缓存
- 定时调度: 多任务分布式时间调度引擎
- 消息通道: Web Push (RFC 8292 / VAPID 浏览器原生横幅通知)
- 前端交互: HTML5 / CSS3 / 手绘风格组件库 (Wired Elements)
- 基础设施: Ubuntu Server / Nginx 本地静态直出与 Gzip 极速压缩
